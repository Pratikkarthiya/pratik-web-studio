# Pratik Web Studio

Responsive static website for Pratik's website design business.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy

For Cloudflare Pages, connect this repository, choose no framework, leave the build command empty, and use the repository root as the output directory.

For GitHub Pages, select Settings → Pages → Deploy from a branch → main → / (root).

## Contact section

The enquiry form prepares a copyable message; it does not send or store submissions. Add verified business email and WhatsApp contact details before using it to receive enquiries.

The portfolio designs are illustrative concepts, not completed customer projects.
